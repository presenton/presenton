# 02. Превью слайдов картинками — реализовано

Записка к разделу «Превью слайдов» из `fyi.md`. Эндпоинт работает, Mini App
может показывать слайды картинками, не поднимая редактор.

## POST /api/v1/ppt/presentation/{id}/preview

`{id}` — id презентации (`data.presentation_id` из задачи генерации).

Тело (можно вообще без тела):

```json
{ "pptx_path": "<path из завершённой задачи генерации>" }
```

Ответ `200`:

```json
{
  "slides": [
    "/app_data/exports/users/<user_id>/previews/<presentation_id>/slide-1.png",
    "/app_data/exports/users/<user_id>/previews/<presentation_id>/slide-2.png"
  ],
  "width": 1280,
  "height": 720
}
```

Картинки открываются по той же сессионной куке (`credentials: "include"`),
порядок — по слайдам.

## Про pptx_path

- **Передавай, если есть**: это `data.path` из завершённой задачи
  (`GET /api/v1/async-tasks/{task_id}`). Рендер пойдёт сразу из готового файла.
- **Не передавай — экспортируем сами**: запустится headless Chromium и сначала
  соберётся свежий PPTX. Работает, но заметно медленнее.
- Превью делается только из PPTX. Если генерация была с `export_as: "pdf"`,
  пришли запрос без `pptx_path` — соберём PPTX сами.
- Повторный запрос по неизменному PPTX отдаёт готовые картинки без рендера
  (кэш по времени изменения файла).

## Коды ошибок

- `404` — презентация не найдена или чужая (изоляция по владельцу).
- `403` — `pptx_path` указывает на файл не этого пользователя.
- `422` — `pptx_path` не `.pptx`.

## Ограничения v1

- Кастомные загруженные шрифты в превью пока не подтягиваются — слайды
  отрендерятся со шрифтами по умолчанию. Скажи, если критично, добавим.
