## Что сделано

Код нового бэкенд-кода не потребовался: `GET /api/v1/quota` (P4) уже годится
обеим поверхностям — веб потребляет его с P8. Задача была договорной:

- `docs/tg/fyi.md`: «имя уточним» → эндпоинт объявлен готовым, формат и
  обработка 401 описаны; вопрос «что показывать по квоте» закрыт и перенесён
  в раздел закрытых; «Квоты подключаем после» → «уже работают».
- `docs/tg/03-quota.md`: новая секция «Как это использовать боту» —
  пошаговый UX (перелогин при 401, блок кнопки при remaining: 0, отсчёт при
  429 из Retry-After, не кэшировать надолго — окно скользящее).
- Тест: `GET /api/v1/quota` без сессии отвечает `401` — это явно оговорено
  в контракте для бота, теперь покрыто (9 тестов в suite).
